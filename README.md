# iso-codes-java

Java enums and classes for [Debian's iso-codes](https://salsa.debian.org/iso-codes-team/iso-codes)
(ISO 639, 3166, 4217 and 15924). The artifact version is the iso-codes release the code was generated from.

```kotlin
dependencies {
    implementation("com.wwwdottheinternetdotcom:iso-codes:4.20.1")
}
```

```java
import com.wwwdottheinternetdotcom.isocodes.iso3166.Country;

Country de = Country.DE;
de.alpha3();                          // "DEU"
de.officialName();                    // Optional[Federal Republic of Germany]
Country.fromNumeric("276");           // Optional[DE]
Subdivision.fromCode("US-CA");        // Optional[US-CA]
Language.fromAlpha3("eng").map(Language::englishName); // Optional[English]
```

| Standard   | Type                     | Kind  | Lookups                                          |
|------------|--------------------------|-------|--------------------------------------------------|
| ISO 3166-1 | `iso3166.Country`        | enum  | `fromAlpha2`, `fromAlpha3`, `fromNumeric`        |
| ISO 3166-2 | `iso3166.Subdivision`    | class | `fromCode`, `all()`                              |
| ISO 3166-3 | `iso3166.FormerCountry`  | enum  | `fromAlpha4`                                     |
| ISO 4217   | `iso4217.Currency`       | enum  | `fromAlpha3`, `fromNumeric`                      |
| ISO 15924  | `iso15924.Script`        | enum  | `fromAlpha4`, `fromNumeric`                      |
| ISO 639-2  | `iso639.LanguagePart2`   | enum  | `fromAlpha3`, `fromAlpha2`, `fromBibliographic`  |
| ISO 639-3  | `iso639.Language`        | class | `fromAlpha3`, `fromAlpha2`, `fromBibliographic`, `all()` |
| ISO 639-5  | `iso639.LanguageFamily`  | enum  | `fromAlpha3`                                     |

## Where the code comes from

Everything under `src/main/java` and the `iso-codes.version` file are generated by
[bigMemer/iso-codes-source-generation](https://github.com/bigMemer/iso-codes-source-generation) and arrive here
only as pull requests from that repo. Don't edit them by hand; change the generator instead. This repo contains
just enough Gradle build to compile, document and publish them.

## Releasing

The **Release** workflow (manual) publishes the version in `iso-codes.version` to Maven Central if it isn't there
already. It defaults to a dry run. It needs these repository secrets: `MAVEN_CENTRAL_USERNAME`,
`MAVEN_CENTRAL_PASSWORD` (a Central Portal user token), `SIGNING_KEY` (ASCII-armored GPG private key) and
`SIGNING_KEY_PASSWORD`.
